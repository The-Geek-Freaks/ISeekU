# ISeekU Mobile — Capacitor Shell

This directory contains the Capacitor shell that wraps the ISeekU React build
for Android and iOS. The React application itself lives in `src/` and builds
to `build/`. Capacitor does not change the application; it embeds it in a
native container and gives it access to device APIs.

## What is and is not done

**Done:**

- `capacitor.config.json` points the shell at the React build (`../build`).
- `package.json` declares the Capacitor dependencies at version 6.x.
- `src/transport/websocket.js` implements RFC 7395 XMPP-over-WebSocket with
  the same security posture as the desktop client. All 43 tests pass.

**Not done (requires the Owner's machine):**

- The `android/` and `ios/` native project directories are not committed.
  `npx cap add android` generates them from the template and they contain
  Gradle wrapper binaries and Xcode project files that belong outside the repo.
- Producing a signed APK requires Android Studio, a JDK, and a signing
  keystore that belongs only on the Owner's machine.
- Producing an IPA requires Xcode, an Apple Developer account, and a signing
  certificate.

## The bridge

The icqr.net server speaks only raw TCP XMPP. Mobile JavaScript cannot open
raw TCP sockets. A WebSocket-to-TCP bridge is required.

**What the bridge does:** it accepts a WebSocket connection from the app and
forwards every byte to `132.145.202.182:5222` as a plain TCP stream. From the
server's point of view it is talking to a normal XMPP client.

**What the bridge sees:** every byte of the session — including the SASL PLAIN
password, in cleartext — because the icqr.net server offers no encryption. See
`docs/adr/0004-mobile-is-capacitor-over-a-bridge.md` for why ISeekU ships no
public bridge.

**Running your own bridge with websockify:**

```
pip install websockify
websockify 8080 132.145.202.182:5222
```

This opens a WebSocket listener on port 8080 on the machine running the
command. The app then connects to `ws://that-machine:8080`. Run it on your
local machine or a machine you control — not a shared host.

**Adding TLS to the bridge:**

```
websockify --cert=cert.pem --key=key.pem 8443 132.145.202.182:5222
```

With a valid certificate the app can use `wss://that-machine:8443`. Without
TLS the transport's security gate refuses the connection unless the Owner
explicitly accepts it.

**Pointing the app at the bridge:**

Open `src/components/LoginPanel.js` (or wherever the XMPP connection is
initiated) and pass the bridge URL as the `url` option to `WebSocketTransport`,
alongside `allowInsecure: true` if the bridge does not use TLS. The URL is not
in `capacitor.config.json` — it is a runtime setting the Owner configures, the
same way the desktop client stores the server address.

## Commands the Owner runs

All commands run from this directory (`mobile/`) unless noted.

### 1. Install Capacitor

```sh
npm install
```

### 2. Build the React application

From the project root (`..`):

```sh
npm run build
```

The build output goes to `../build/`, which is where `capacitor.config.json`
points.

### 3. Add the native platforms (first time only)

```sh
npx cap add android
npx cap add ios
```

`add android` requires a JDK on the PATH. `add ios` runs only on macOS with
Xcode installed.

### 4. Sync the web build into the native projects

After every `npm run build`:

```sh
npx cap sync
```

This copies `../build/` into both native projects and updates Capacitor
plugins.

### 5. Run on a connected device or emulator

```sh
npx cap run android   # opens Android emulator or connected device
npx cap run ios       # opens iOS Simulator or connected iPhone
```

### 6. Open in the native IDE (for signing and release builds)

```sh
npx cap open android  # opens Android Studio
npx cap open ios      # opens Xcode
```

### 7. Build a signed APK (Android Studio)

In Android Studio:

1. **Build → Generate Signed Bundle / APK**
2. Choose **APK**, then create or select a keystore.
3. Select **release** build variant.
4. The signed APK appears in `android/app/release/`.

From the command line (after configuring `android/app/build.gradle` with the
keystore):

```sh
cd android
./gradlew assembleRelease
```

### 8. Build an IPA (Xcode)

1. Open the project with `npx cap open ios`.
2. Select the ISeekU target.
3. **Product → Archive**.
4. In the Organiser, choose **Distribute App**.
5. Follow the signing and export steps.

## Notes on the generated native projects

`android/` and `ios/` are generated by Capacitor and should be added to
`.gitignore`. They change on every `cap sync` and contain binary files
(Gradle wrapper, Xcode indexes) that do not belong in a JavaScript repo.
The `capacitor.config.json` and `package.json` in this directory are the
source of truth; the native projects are derived artefacts.

Add to the root `.gitignore`:

```
mobile/android/
mobile/ios/
mobile/node_modules/
```
